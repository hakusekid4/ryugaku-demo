# Ryugaku Agent デモ

留学エージェント向け WordPress テーマ「Ryugaku Agent」のデモ配布用リポジトリです。

## デモを開く(ブラウザだけで動きます)

https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/hakusekid4/ryugaku-demo/main/blueprint.json

- 表示まで 30 秒〜1 分ほどかかります
- 開くたびに初期状態に戻る「お試し環境」です。自由に操作してください
- 管理画面は `/wp-admin/` (ログイン済み)

## ファイル

- `ryugaku.zip`: テーマ本体(WordPress の 外観 > テーマ > 新規追加 > テーマのアップロード で使えます)
- `blueprint.json`: WordPress Playground 用の自動セットアップ設定
