# その日のページを作る(daily-page)

*2026-10-05 本人決定(ai-config の `docs/plans/ai-config-review/grill.md` #2〜#5)。目的はセッションの題で、実行内容はこのページで示す。作業フィードはやめた。急ぎだけスマホに通知する(口調の決まり第 9 節)。*

## いつ作るか

- **その日に作業した回の最後**に作る。ファイルを変えたか、コマンドを実行して結果が出た回のこと。同じ日に 2 回目以降の作業があれば、同じページを書き換える
- **進捗が無い日は作らない。**読んだだけ、定期起動が正常に回っただけ(取得が通った、など)の回は書き換えない
- ページを作るための定期起動は足さない

## 手順

1. **頭を集める**
   - 題: このセッションの題(目的)。`get_session`(session_id は省く)の `title`。取れなければ、会話の最初に決まった役目を「<プロジェクト>: <役目>」の形で書く
   - 定期起動: `list_triggers` で、`persistent_session_id` がこのセッションのものを拾い、「時刻(日本時間)+ 何をしているか 1 行」にする。道具が無い・取れないときは空(ページには「無し」と出る)
   - 日付: 日本時間の今日(0 時区切り)
2. **4 欄を書く**(1 項目 1 行、事実と数字を先に。本人の口調の決まりに従う)
   - 今日やったこと: 終わったこと(チケットなら「チケット NN「<題>」を done にした」)
   - 数字: 件数・損益・的中率・テストの通過数など。無ければ空
   - 次にやること: 次の 1〜3 手(チケットなら次の前線)
   - 本人に要ること: 本人の判断・作業が要るもの、止まった理由と次の案。無ければ空
3. **HTML にする**: 入力をスクラッチパッド(使い捨ての作業場所)に JSON で書き、道具を通す
   ```
   python .claude/tools/daily_page.py <入力.json> -o <スクラッチパッド>/daily-page.html
   ```
   (ai-config では `scripts/daily_page.py`。入力の形は `--example` / `--example-md` で見られる。題が空なら道具が止まる)
4. **同じリンクで出す**: `Artifact` で publish する。決まりの形(題・色の変数・暗い表示・スマホ幅)は道具の出力が満たしている。ほかに Artifact の道具が求める手順があれば従う
   - このセッションのリンクは、このリポジトリの `.claude/daily-pages.json`(`{"<session_id>": "<リンク>"}`)に控える
   - 控えがあれば、その `url` を渡して書き換える(前の会話で作ったものは、先に `action: "read"` で読んでから)。同じ会話の中で 2 回目なら、同じ `file_path` で出せば同じリンクになる
   - 控えが無ければ新しく出し、出たリンクを控えに書いてコミットする
5. **初回だけ ai-config へ知らせる**: 新しくリンクができたら、`/ai-config-memo` で 1 件送る(ai-config 自身では `python scripts/session_pages.py register --url <リンク> --title "<題>" --session <session_id>`)。見取り図の一覧に載る
   ```
   kind: log / topic: page
   ## 要点
   - page: <リンク>
   - 題: <セッションの題>
   - セッション: <session_id>
   ```
6. **急ぎならスマホへ 1 本**: 「本人に要ること」が急ぎ(お金が動いた・動かなかった、失敗・停止・異常、本人が触らないと翌日まで進まない)なら、`PushNotification` で 200 字以内の 1 本を送る。それ以外は通知しない
7. 報告にページのリンクを 1 行添える

## しないこと

- 日ごとに新しいリンクを作る(1 セッション 1 リンク。本人がブラウザに登録できるように)
- 進捗の無い日にページを書き換える
- 本人の判断が要ることをページに書いただけで済ませる(台帳 `ai-systems/open-decisions.md` へも積む。ai-config 以外からは `/ai-config-memo` の `kind: question`)
- 鍵・トークン・他人の個人情報をページに載せる
